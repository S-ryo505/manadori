# まなドリ

教科書から作った問題を、間隔反復（まちがえた問題ほど早く再出題）と模擬テストで定着させる学習アプリです。

- トップページで教科（社会・英語・理科…）を選んで学習します。
- 問題データ（.json）は、アプリの「設定 → ファイルから読み込む」で端末に取り込みます。
- 問題データ・学習記録は、使っている端末の中（ブラウザの保存領域）にだけ保存されます。このリポジトリには入れません。
